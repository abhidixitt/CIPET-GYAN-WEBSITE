# CIPET GYAN

**CIPET GYAN** is a focused learning platform for CIPET students, providing study materials, course resources, previous-year papers, video learning, mock tests, and student reviews.

## Live Website

[Visit CIPET GYAN](https://cipetgyan.me/)

## Features

- Responsive CIPET GYAN homepage
- Study materials and learning resources
- Notes, syllabus, and previous-year papers
- Video learning section
- Promo video section
- Mobile app showcase carousel
- Mock test information
- Student reviews
- Masked WhatsApp student review screenshots
- Contact information
- WhatsApp, YouTube, and Telegram links

## Technology

- React
- Vite
- JavaScript
- HTML
- CSS

## Run Locally

Install the dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

The local development URL and port will be displayed in the terminal by Vite.

## Build

Create a production build using:

```bash
npm run build
```

The production files will be generated inside the `dist` directory.
