# CIPET GYAN

CIPET GYAN is a focused learning platform for CIPET students, with study materials, course screens, previous-year papers, video learning, mock tests, and student reviews.

Currently, two official plugins are available:

## Website

[Visit the live website](https://cipetgyan.netlify.app/)

## Run locally

```bash
npm install
npm run dev
```

The local development server runs on the Vite port shown in the terminal.

## Build

```bash
npm run build
```

## Included

- Responsive CIPET GYAN homepage
- Promo video and YouTube video section
- Mobile app carousel using screens from the promo video
- Study material cards for notes, syllabus, and previous-year papers
- Masked WhatsApp student review screenshots
- Contact details and social links for WhatsApp, YouTube, and Telegram
